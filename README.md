## Compilation
To compile the project, use the following command:

```
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 -Wno-format -I./include *.c src/*.c -o main
```
Make sure to account for the folder structure and compile src/*.c, in addition to the header file in the included directory.
